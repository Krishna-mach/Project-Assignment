# Telecom Churn Prediction

## Business Problem

Customer churn is one of the biggest challenges in the telecom industry. Acquiring new customers is often more expensive than retaining existing ones.

## Objective

Predict whether a customer is likely to leave (churn) based on their demographics, service usage, and account information.

## Dataset Features

- Gender
- Senior Citizen
- Partner
- Dependents
- Tenure
- Phone Service
- Internet Service
- Contract Type
- Monthly Charges
- Total Charges

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Data Preprocessing
6. Model Building
7. Model Evaluation
8. Business Insights

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC Score

## Key Business Insights

- Month-to-month contract customers have higher churn rates.
- Customers with shorter tenure are more likely to churn.
- Higher monthly charges can increase churn probability.
